# 📄 NLP Document Q&A App

An intelligent **Document Question Answering System** built using **Natural Language Processing (NLP)** and **Streamlit**.

The application allows users to interact with document content and retrieve relevant answers through a simple web interface.

---

## 🚀 About the Project

The **NLP Document Q&A App** is designed to simplify information retrieval from documents.

Instead of manually searching through large amounts of text, users can ask questions and the system processes the document content to provide relevant answers.

This project demonstrates the practical application of **Natural Language Processing and Question Answering techniques**.

---

## ✨ Features

- 📄 Document-based Question Answering
- 💬 Simple question input interface
- 🧠 Natural Language Processing
- ⚡ Fast document information retrieval
- 🖥️ Interactive Streamlit web application
- 🎯 Easy-to-use user interface

---

## 🛠️ Technologies Used

- **Python**
- **Natural Language Processing (NLP)**
- **Streamlit**
